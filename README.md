# HR Employee Attrition Analysis (SQL)

## Project Overview

This project analyzes employee attrition using SQL to answer business questions and identify patterns related to employee turnover.

---

## Business Problem

The objective of this project is to use SQL queries to explore employee data and uncover insights that can help improve employee retention.

---

## Dataset

- IBM HR Analytics Employee Attrition Dataset
- Total Employees: 1,470

---

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- CASE WHEN
- HAVING
- CTE
- Window Functions
- Aggregate Functions

---

## Business Questions

- Overall Attrition
- Attrition by Department
- Attrition by Job Role
- Average Monthly Income by Job Role
- Employees Above Average Salary
- Attrition by Age Group
- Overtime Analysis
- Job Satisfaction Analysis

---

## Key Insights

- Sales and Research & Development experienced the highest attrition.
- Employees working overtime were more likely to leave.
- Younger employees showed higher turnover.
- Salary and job role influenced employee retention.
